Everything under `data/`, `docs/`, and `tools/*/` — the directory records, the
schema, the Standards of Excellence framework, and the written content — is
licensed **[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)**.

Source code (everything else) is MIT — see `LICENSE`.

## Why share-alike for the data

Two reasons, both practical:

1. **Compatibility with Open Know-Where.** The Internet of Production
   Alliance publishes OKW under CC BY-SA 4.0. We ingest and contribute back to
   that ecosystem; share-alike keeps the round trip legal without per-record
   negotiation.
2. **A directory that can be taken but not enclosed.** Anyone may copy this
   dataset, run their own state or regional instance, and fork away from us
   entirely — that is the point. Share-alike only asks that improvements to the
   data stay as open as they arrived.

Code is MIT precisely so it can be embedded anywhere, including in commercial
and proprietary systems, with no obligation.
