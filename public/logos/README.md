Each space's own logo, recovered from the superseded Connecticut Google Site and
resized to fit within 480px. These marks belong to the spaces and are **not**
covered by the repository's CC BY-SA data licence — see `LICENSE-DATA.md`.

Filenames match the space `id`, and each record points at its file through
`logo_url`. A record without a logo simply omits the field; the directory falls
back to a monogram. Do not add a logo here without also adding the `logo_url`
and a `sources[]` entry saying where it came from.
